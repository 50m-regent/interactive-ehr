# 口頭試問会原稿

Notionの研究ダッシュボードと関連ページ、`socguide202304.doc`の作成要領を基にしたLaTeX原稿です。

## ビルド

TeX Live 2024以降で次を実行します。

```bash
make
```

最終PDFは`output/pdf/Hirata_Ren.pdf`へ生成されます。中間生成物は`build/`へ保存されます。

## 資料の時点

この原稿は2026年8月27日時点の研究状態を記録した成果物です。原稿中では正式評価用データを未実行として扱っています。その後に実施した正式評価の結果は、リポジトリ直下の`README.md`と`results/evaluation/tracebench_ehr_v1.1/test/`を参照してください。

## 原稿で扱う結果

- 修正版の評価設計を使った最終評価前の動作確認までを、確認済みの結果として記載しています。実験ファイル上の版番号はv1.1です。
- 調整確認用データでは、924件の基準ケースから758組、6,064候補を生成し、8種類の不整合が事前に定めた最小件数を満たしました。
- 2026年8月27日時点では最終評価用データは未実行でした。4種類の検査方法の差と、一回の自動修正の成功率は未確定として記載しています。
- 研究質問、比較条件、指標、確認済みの結果、次の作業が対応する構成にしています。
