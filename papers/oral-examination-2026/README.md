# 中間諮問会原稿

Notionの研究ダッシュボード、院内運用記録、正式技術評価の結果を基にした中間諮問会用のLaTeX原稿です。電子カルテ利用時の認知負荷軽減を研究全体の目的とし、タスクグラフによるUI生成、院内実装、整合性の技術評価、卒業までに行うユーザー評価を一つの流れで説明します。

## ビルド

TeX Live 2024以降で次を実行します。

```bash
latexmk main-revised.tex
cp build/main-revised.pdf output/pdf/Hirata_Lenne_revised.pdf
```

確認用PDFは`output/pdf/Hirata_Lenne_revised.pdf`です。中間生成物は`build/`へ保存されます。

## 資料の時点

この原稿は2026年9月6日時点の研究状態を記録しています。院内サーバーでの動作確認と、層間整合性の正式技術評価を反映しています。認知負荷の軽減を確かめるユーザー評価は未実施であり、卒業までに行う計画として記載しています。

## 原稿で扱う結果

- 院内DWHの135表を取り込んだ提案システムが院内サーバーで応答することを、確認済みの実装結果として記載しています。
- 正式技術評価では、934件の基準UIを構築し、763組、6,104回の候補検証を行いました。
- グラフ契約とサイドカー契約は、不整合763件をすべて拒否し、妥当な更新763件をすべて受理しました。
- 技術評価は利用評価の前提であり、認知負荷の軽減を直接示さないことを明記しています。
- 必要な専門家確認、倫理審査、院内の実施許可が整えば、卒業までに現行電子カルテと提案UIを比較するユーザー評価を行う計画を記載しています。
